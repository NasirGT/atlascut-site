Privacy Policy

Last updated: November 6, 2026

AtlasCut Uploader ("the tool") is an internal tool that publishes AtlasCut's own videos to AtlasCut's own TikTok account.

What data the tool uses

When AtlasCut authorises the tool with Login Kit, TikTok provides an access token and basic profile information (display name, avatar, open ID) for the AtlasCut account only. The tool uses these only to upload videos and to check that an upload succeeded.

What we do not collect

The tool does not collect, store or process data about any other TikTok user, viewer or follower. It has no public sign-up and no analytics or advertising trackers.

Storage and security

Access tokens are stored only on AtlasCut's own computer, are never shared, sold or published, and can be revoked at any time from TikTok's settings.

Deletion

Revoking access in TikTok removes the tool's permission immediately. AtlasCut deletes the stored token when access is revoked.
